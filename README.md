\# OTT Platform



Full-stack OTT streaming platform built with modern web technologies.



\## Project Structure



```text

ott-platform/

├── ott-backend/

└── ott-frontend/

```



\## Backend



The backend is located in the `ott-backend` directory.



Technologies:



\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT

\- Cloudinary

\- Swagger

\- Joi

\- Morgan

\- Express Rate Limit



Detailed backend documentation is available in:



```text

ott-backend/README.md

```



\## Frontend



The frontend will be developed in the `ott-frontend` directory using:



\- React

\- Vite

\- React Router

\- Axios
